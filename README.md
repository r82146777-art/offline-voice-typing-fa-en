# تایپ صوتی آفلاین (فارسی + انگلیسی)

اپلیکیشن تایپ صوتی **کاملاً آفلاین** بعد از دانلود اولیه مدل‌ها، مناسب افراد بینا و نابینا.

## ویژگی‌های فعلی
- UI مدرن Material 3 + تم روشن/تاریک
- دسترسی‌پذیری قوی (Semantics، دکمه‌های بزرگ، بازخورد صوتی TTS، مناسب TalkBack)
- سوئیچ آسان بین فارسی و انگلیسی
- دانلود خودکار مدل‌های Vosk در اولین اجرا
- آماده برای اتصال واقعی به موتور تشخیص گفتار

## وضعیت توسعه
- [x] ساختار کامل Flutter
- [x] UI دسترسی‌پذیر و جذاب
- [x] سرویس TTS
- [x] دانلود خودکار مدل‌ها
- [x] اسکلت STT با پشتیبانی دو زبانه
- [ ] اتصال کامل پلاگین Vosk (نیاز به تست روی دستگاه)
- [ ] پیاده‌سازی کیبورد سیستم (IME)
- [ ] ویجت صفحه اصلی

## چگونه بسازید و اجرا کنید

### پیش‌نیاز
- Flutter 3.22 یا بالاتر
- Android SDK

```bash
git clone https://github.com/r82146777-art/offline-voice-typing-fa-en.git
cd offline-voice-typing-fa-en
flutter pub get
flutter run
```

در اولین اجرا اپ مدل‌های لازم را خودش دانلود می‌کند (حدود ۹۰ مگابایت).

### ساخت APK
```bash
flutter build apk --release
```
فایل خروجی:
`build/app/outputs/flutter-apk/app-release.apk`

## مدل‌ها
- فارسی: vosk-model-small-fa-0.42
- انگلیسی: vosk-model-small-en-us-0.15

لینک رسمی: https://alphacephei.com/vosk/models
